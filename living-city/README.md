# Hanasou — The Living City

A fresh visual and interaction concept for Hanasou, built separately from the original app and the existing Speaking Studio preview.

## Direction
- Illustrated travel journal meets everyday Japanese neighborhood.
- Warm paper, imperfect ink contours, muted greens, persimmon red, indigo, and ochre.
- The map is an orientation device, not the whole personality of the app.
- The learner is asked to speak before revealing the model answer.
- Four practice modes: Say it yourself, Catch the meaning, Make it your own, Use it out there.
- Four bottom destinations: Today, Explore, Practice, Journal.

## Run
Open index.html from GitHub Pages at /living-city/. No build step or external JS libraries. The custom SVG is an original vector illustration; lesson text stays in HTML for clarity and accessibility.

The prototype stores only its own lightweight practice count in localStorage under hanasou-living-city-v1. Existing app progress, lesson data, audio, and voices are not modified.
